# Cost Estimation

Estimate only with stated assumptions. Include material, support/purge, machine time, electricity, failure allowance, hardware, adhesives, labor, post-processing, packaging, shipping, tool wear, and outsourcing. Report ranges when inputs vary; do not label rough assumptions as exact unit cost.


## Reproducible estimate

Keep one-time setup/tooling/design cost separate from recurring attempt cost and cost incurred only for accepted units. State currency, date, quantity basis, and whether tax/shipping are included.

For N accepted units, assumed yield y (0 < y <= 1), and cost c per attempted unit, use N/y attempts as a planning expectation. Expected total = setup + (N/y)*c + N*accepted-unit finishing/packaging cost. Report expected cost per accepted unit as total/N. This assumes comparable independent attempts and no salvage; correlated plate failures, rework, and partial batch losses need explicit scenarios. Round up actual scheduled plates or purchases, not intermediate arithmetic.

Include support/purge once in material cost. If a machine hourly rate includes electricity, depreciation, or maintenance, do not add them again. Separate hands-on labor from unattended cycle time. If yield is unknown, show named yield scenarios instead of claiming a measured rate. Compare processes at the same accepted quantity, finish, inspection, and delivery scope.

Example arithmetic only: setup 40, attempt cost 3, yield 0.80, accepted-only finishing 1, and 20 accepted units gives expected total 135 and 6.75 per accepted unit, in the stated currency. This is an expectation, not a quote or delivery guarantee.
