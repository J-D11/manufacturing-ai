# Start with the next useful step

Use this route when the person is new to printing or unsure where to begin. Keep the authoritative gates in SKILL.md, but expose only the decisions needed now. Do not turn a simple question into a form. Explain a new term in the sentence where it first matters.

## Pick the entry point

Ask which outcome they want only if it is unclear: make something from an idea, print an existing model, or fix a failed print. Ask at most two or three high-value questions together. Use answers already present in the conversation.

**“I have an idea.”** Ask what it must do and what it must fit around or attach to. Ask for measurements when fit matters; a photo without a scale does not establish dimensions. Check whether failure could hurt someone or damage property. Offer a rough concept with assumptions labeled, then the smallest physical test. A storage box needs different decisions from a replacement part in a vehicle.

**“I downloaded a model.”** Request or inspect the file, identify units and intended size, and ask which printer and material are available. A model image cannot establish mesh integrity. Compare the file's overall dimensions with the intended use before changing scale. If sharing or selling is part of the request, inspect the source license rather than assuming permission.

**“My print failed.”** Establish whether the machine is still running and whether there is an immediate hazard. Ask for the symptom, when it appeared, and the machine/material/profile combination. Preserve the failed file and settings. Separate what is visible from possible causes; choose one useful observation or controlled test before changing settings. Route printer-specific diagnosis to the relevant available specialist.

**“I don't own a printer.”** Offer a file-preparation or supplier-handoff route. Ask the provider for its process and file requirements before promising fit, price, or turnaround. Owning a printer is not a prerequisite for learning the workflow.

## Make the action achievable

Check available tools before offering to operate them. When CAD (software for making dimensioned geometry) is available, create or edit a versioned model and inspect the result. Otherwise provide a short sequence of sketch dimensions and operations that the user can follow in their chosen application. Do not invent button names for an uninspected application version.

A slicer converts a model into machine instructions. Select the actual machine, nozzle, build surface, and compatible material profile; never substitute a guessed setup. Preview means inspecting the generated layer paths, not just the solid model. Explain which feature to look at: missing text, unsupported regions, gaps, or a color transition. A successful slice is preparation evidence, not a successful print.

If missing information blocks only a later step, continue with a labeled concept or read-only inspection. If it blocks safe machine operation, stop that operation and give one concrete next action. For multiple steps, keep a short record of the file revision, setup, test, and result behind the scenes.

## End with a handoff they can follow

Example: “Next, measure the widest part this lid must cover. Record the measurement in millimeters. That lets us design a short rim test before printing the whole box.” Once the fact is available, continue rather than re-asking it.

Offer the relevant example: [storage enclosure](examples/enclosure.md), [fitted desk bracket](examples/fitted-bracket.md), or [multicolor sign](examples/multicolor-sign.md). These are illustrative learning projects, not tested designs or approved print profiles. Adapt to the person's tools and purpose. Ask for physical results when they are necessary; never imply the assistant has touched or measured a part.
