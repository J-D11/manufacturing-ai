# Calibration

Calibrate only when it changes the decision: bed level, flow, pressure advance, temperature, retraction, bridging, overhang, dimensions, holes, tolerance, first layer, support interface, multicolor purge, or drying. State what the test proves and the pass criterion. Preserve successful settings with machine, nozzle, plate, material, and version context.

Before calibration, verify the configuration fingerprint and physical condition: machine/tooling, workholding or build surface, material and lot, relevant profile, environment, cleanliness, and readiness. Record which changes invalidate the result.

For a controlled rerun, record the baseline, held constants, planned variable, setting or behavior actually delivered at the machine, and physical response. Transfer only the proven delta into production, then rerun every dependent digital and physical gate.
