# Changelog

## v1.1.0

- Add read-only asset inspection, dimensional relationship checks and native Bambu job preflight.
- Check expected insertion pauses, printer/nozzle identity and G-code checksum.
- Document two-color alignment, filament mapping and recovery from unreliable part-list editing.
- Add reference-based logo reconstruction and dependent-dimension checks.
- Introduce scoped physical-test reuse and explicit current-version records.
- Include beginner workflows, editable starter models, evaluation scenarios and user-trial templates.
- Add 45 automated tests and a GitHub Actions test workflow.

Physical success remains scoped to the reported setup; digital checks do not certify a new print.
